# 🎓 College Event Portal

## 📌 Project Overview

The **College Event Portal** is a web-based application designed to provide students with an easy and organized way to explore and participate in college events.

The portal displays upcoming events, schedules, event details, registration options, gallery content, and contact information in a simple and user-friendly interface.

## 🎯 Objectives

* Provide information about upcoming college events.
* Display event dates, timings, venues, and descriptions.
* Allow students to register for events.
* Provide an event schedule for easy planning.
* Showcase event photos through a gallery.
* Provide contact information for event-related queries.
* Create a responsive and user-friendly web interface.

## ✨ Features

* 🏠 Home Page
* 📅 Event Listings
* 🕐 Event Schedule
* 📝 Event Registration
* 🖼️ Event Gallery
* 📞 Contact Page
* 📱 Responsive Design
* 🔗 Easy Navigation Between Pages
* ⚡ JavaScript-based Interactive Features

## 🛠️ Technologies Used

* **HTML5** – Structure of the web pages
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality
* **Visual Studio Code** – Development environment
* **GitHub** – Project hosting and version control

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html`.
4. Run the file using a web browser.
5. Navigate through the different pages using the navigation menu.
